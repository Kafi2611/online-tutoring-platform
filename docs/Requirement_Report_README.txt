The Lab 2 instruction requires a Project Design Report PDF in the repository.

Before final submission, export your completed report as:

    docs/Requirement_Report.pdf

The report should include the required sections from the lab manual: cover page, team information, project title, problem statement, objectives, stakeholder analysis, functional and non-functional requirements, user stories/use cases, selected process model, justification, comparison with alternatives, MVP design overview, GitHub collaboration evidence, challenges encountered, and conclusion.
